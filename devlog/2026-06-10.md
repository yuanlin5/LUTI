### 第三轮修复（闪退根因定位）

**关键发现**：qfluentwidgets ComboBox 是 QPushButton 子类，不是 QComboBox！
- 没有 `model()` — 不能用 QStandardItemModel API
- 没有 `view()` — 不能获取下拉视图设置右键菜单
- 没有 `insertSeparator()`
- 正确 API：`setItemEnabled(idx, False)` 禁用选项
- 正确 API：`cb.items` 返回 ComboItem 列表（`item.isEnabled()` 判断状态）

- [x] ui/question_list.py：`_refresh_filters()` 改用 `setItemEnabled(3, False)` 禁用分隔线，用 `_refreshing` 标记防止信号级联
- [x] ui/question_list.py：`_do_search()` 保护改为 `self.cat_filter.items[idx].isEnabled()` 判断
- [x] ui/question_list.py：`_on_tag_context_menu()` 用 `currentData()/currentText()` 替代 `view().indexAt()`
