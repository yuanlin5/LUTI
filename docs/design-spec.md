# 设计规范

## 配色方案

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色 | #4A90D9 | 淡蓝色，用于按钮、选中态、强调元素 |
| 主色悬停 | #357ABD | 按钮悬停状态 |
| 页面背景 | #F5F8FC | 全局背景色 |
| 侧边栏背景 | #E8F0FE | 导航侧边栏 |
| 卡片/输入框背景 | #FFFFFF | 内容卡片和表单控件 |
| 正文文字 | #333333 | 主要内容文字 |
| 次要文字 | #888888 | 辅助说明文字 |
| 正确/通过 | #52C41A | 正确按钮颜色 |
| 错误/失败 | #FF4D4F | 错误按钮颜色 |

## 布局规范

- 窗口默认尺寸：1100 × 750 像素
- 侧边栏宽度：160 像素，固定
- 内容区域内边距：30 像素
- 卡片圆角：10 像素
- 按钮圆角：6 像素
- 输入框圆角：6 像素

## 字体

- 主字体：Microsoft YaHei（Windows 默认中文字体）
- 回退字体：PingFang SC, sans-serif
- 基础字号：14px
- 标题字号：22px（加粗）
- 小字：12px

## 间距

- 组件间标准间距：16 像素
- 区域间距：24 像素
- 卡片内边距：20 像素

## 交互规范

- 侧边栏按钮：选中态高亮蓝色，悬停浅灰背景
- 表格行：悬停时浅蓝背景
- 主要操作按钮：蓝底白字
- 次要操作按钮：白底蓝边
- 删除类操作：红色系
- 确认类操作：绿色系
- 所有操作需给出即时反馈（状态提示）
