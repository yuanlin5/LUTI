# 项目需求文档

## 项目概述
一款运行在 Windows 上的桌面题库管理软件，帮助用户记录和复习平时遇到的错题。

## 功能需求

### 1. 题目录入
- 支持录入问题、答案、备注三个文本字段
- 每个字段均可插入图片
- 提供语音转文字按钮，支持中文语音输入
- 题目可归属到分类
- 题目可添加多个标签

### 2. 题库管理
- 查看所有题目的列表
- 按关键词搜索题目
- 按分类筛选题目
- 按标签筛选题目
- 编辑已有题目
- 删除题目

### 3. 组卷考试
- 支持随机抽题和按分类/标签筛选后抽题两种模式
- 用户设定抽题数量
- 逐题展示，先隐藏答案
- 用户点击"显示答案"后查看答案
- 用户自行判断正确或错误
- 系统记录每道题的做错次数

### 4. 错题集
- 自动收集所有做错过的题目
- 按做错次数降序排列
- 支持搜索和分类筛选
- 可重置单题的错题计数（表示已掌握）

### 5. UI 要求
- 简洁、直观的界面设计
- 淡蓝色作为主色调
- 侧边栏导航，内容区切换
